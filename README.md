# Calculator

A simple console-based calculator built with C# and .NET.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid number input
- Handles invalid operations
- Prevents division by zero
- Allows repeated calculations

## Technologies

- C#
- .NET

## How to Run

1. Clone the repository.
2. Open `Calculator.slnx` in Visual Studio.
3. Build the solution.
4. Run the application using `Ctrl + F5`.
